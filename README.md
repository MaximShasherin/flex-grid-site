# Flexbox и Grid — Современная вёрстка CSS

##  Тема проекта
Учебный сайт, посвящённый двум основным системам макетирования в CSS — Flexbox и Grid. 
Сайт содержит теоретический материал, сравнительную таблицу, практические примеры и интерактивные демонстрации.

##  Цель
Продемонстрировать возможности Flexbox и Grid для создания адаптивных макетов, а также помочь начинающим разработчикам освоить эти технологии.

##  Технологии
- HTML5
- CSS3 (Flexbox, Grid, медиа-запросы, анимации)
- JavaScript (навигация, интерактивные демонстрации, счётчик посещений)
