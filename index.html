Flexbox и Grid — архитектура современного CSS

✨ Две главные системы макетирования, которые заменили устаревшие приёмы (float, таблицы). Flexbox управляет выравниванием в одной оси, а Grid даёт полный контроль над строками и столбцами одновременно.

📦 Flexbox

Одномерная модель для выравнивания элементов в строке или колонке. Идеальна для:

  • Навигационных меню
  • Центрирования элементов
  • Карточек и списков

🗂️ Grid

Двумерная модель для создания сложных сеток. Идеальна для:

  • Общей структуры страницы
  • Галерей и дашбордов
  • Сложных макетов

💡 Когда что использовать?

Flexbox — для компонентов интерфейса (кнопки, меню, центрирование).
Grid — для каркаса страницы (шапка, основная часть, футер).

Flexbox: одномерный layout

Flexible Box Layout — инструмент для распределения элементов вдоль главной оси (row | column). Идеально для меню, карточек, выравнивания по центру.

📌 Свойства контейнера

  • display: flex; — активирует flex-контекст
  • flex-direction: row | column — направление оси
  • justify-content — выравнивание по главной оси
  • align-items — выравнивание по поперечной оси
  • gap — расстояние между элементами

📌 Свойства элементов

  • flex: grow shrink basis; — гибкость элемента
  • flex: 1; — занимает всё доступное место
  • align-self — переопределяет align-items
  • order — меняет порядок

📌 Пример кода (горизонтальное меню)

<ul class="flex-nav">
  <li>Главная</li>
  <li>О нас</li>
  <li>Услуги</li>
  <li>Контакты</li>
</ul>

.flex-nav {
  display: flex;
  justify-content: space-around;
  background: #f3f4f6;
  padding: 1rem;
}

🎯 Центрирование через Flexbox

.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
}

Благодаря flex-контейнеру можно идеально отцентрировать любой элемент по вертикали и горизонтали — революция для CSS!

⚠️ Ошибки новичков

  • Забывают про flex-wrap на мобильных
  • Используют flex: 1 без понимания
  • Путают justify-content и align-items

CSS Grid Layout — двумерное могущество

Grid работает одновременно со строками и столбцами, превращая контейнер в полноценную сетку. Основные понятия: линии (grid lines), треки (track), ячейки (cell) и области (grid area).

📌 Свойства контейнера

  • display: grid; — включает Grid
  • grid-template-columns: 1fr 2fr 1fr; — столбцы
  • grid-template-rows: auto 200px; — строки
  • gap: 16px; — расстояние между треками
  • grid-template-areas — именованные области

📌 Свойства элементов

  • grid-column: 1 / 3; — занимает столбцы 1-2
  • grid-row: 2 / 4; — занимает строки 2-3
  • grid-area — ссылается на именованную область

📐 Пример кода: адаптивная сетка

.grid-demo {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 20px;
}

Сравнение Flexbox и Grid

Выбор между Flexbox и Grid зависит от задачи. Вот подробное сравнение:

ХарактеристикаFlexboxGrid
ИзмерениеОдномерная (строка ИЛИ колонка)Двумерная (строки И столбцы одновременно)
Основная задачаВыравнивание элементов в одном направлении, распределение пространства, навигация, карточки.Создание сложных макетов, цельных сеток, расположение элементов в двух осях.
Управление содержимымОриентация на контент (размер элементов влияет на сетку)Ориентация на контейнер (задаём структуру явно)
Когда использоватьМеню, центрирование, небольшие UI-компоненты, выравнивание кнопокОбщая структура страницы, сложные галереи, панели, дашборды, новостные сетки
Свойстваjustify-content, align-items, flex-grow, ordergrid-template-areas, grid-template-columns/rows, gap, justify-items

🔍 Рекомендация: Используйте Flexbox для мелких интерфейсных элементов и внутреннего выравнивания. Применяйте Grid для каркаса страницы, чтобы полностью контролировать расположение блоков.

Примеры и учебные задачи

Решение двух базовых задач: навигация через Flexbox и сетка из трёх одинаковых колонок через Grid.

✅ Задача 1 (Flexbox): навигация с равными расстояниями

Условие: элементы списка — навигация, нужно расположить в ряд с равными промежутками. Используем display: flex; justify-content: space-around;.

  • 🏠 Главная
  • 📰 Блог
  • 📞 Контакты
  • 🔧 Услуги
nav ul {
  display: flex;
  justify-content: space-around;
  flex-wrap: wrap;
}

✅ Задача 2 (Grid): три колонки одинаковой ширины

Условие: элементы разного размера, но должны образовать 3 одинаковых столбца. Используем grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

📦 Короткий текст
📦 Очень длинное содержимое, которое показывает, что ширина ячейки остаётся идеально равной благодаря системе Grid
📦 Средний текст
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}
