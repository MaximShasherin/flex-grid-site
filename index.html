Flexbox и Grid — архитектура современного CSS

✨ Две главные системы макетирования, которые заменили устаревшие приёмы (float, таблицы). Flexbox управляет выравниванием в одной оси, а Grid даёт полный контроль над строками и столбцами одновременно.

Зачем они нужны?

Раньше разработчикам приходилось использовать хаки: float, clearfix, относительное позиционирование. Сегодня Flexbox и Grid позволяют создавать адаптивные, гибкие и сложные макеты всего несколькими строками CSS. Они идеально подходят для отзывчивого дизайна, центрирования, умного распределения пространства и построения сеток новостных порталов, интернет-магазинов и дашбордов.

Flexbox: одномерный layout

Flexible Box Layout — инструмент для распределения элементов вдоль главной оси (row | column). Идеально для меню, карточек, выравнивания по центру.

Основные свойства контейнера

  • display: flex; — активирует flex-контекст.
  • flex-direction: row | column | row-reverse | column-reverse — направление оси.
  • justify-content — выравнивание по главной оси (flex-start, center, space-between...).
  • align-items — выравнивание по поперечной оси (stretch, center, flex-start...).

Свойства элементов: flex

Сокращённое свойство flex: grow shrink basis; позволяет управлять гибкостью. Например flex: 1; заставит элемент занимать всё доступное место.

📌 Пример кода (горизонтальное меню с равными отступами)

<ul class="flex-nav">
  <li>Главная</li>
  <li>О нас</li>
  <li>Услуги</li>
  <li>Контакты</li>
</ul>

.flex-nav {
  display: flex;
  justify-content: space-around;
  background: #f3f4f6;
  padding: 1rem;
}
🎯 элементы равномерно распределены, при наведении — hover-эффект (цвет + масштаб).

Центрирование через Flexbox

.parent {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
}

Благодаря flex-контейнеру можно идеально отцентрировать любой элемент по вертикали и горизонтали.

CSS Grid Layout — двумерное могущество

Grid работает одновременно со строками и столбцами, превращая контейнер в полноценную сетку. Основные понятия: линии (grid lines), треки (track), ячейки (cell) и области (grid area).

Ключевые свойства контейнера

  • display: grid; — включает Grid.
  • grid-template-columns: 1fr 2fr 1fr; — задаёт столбцы (fr — доля свободного места).
  • grid-template-rows: auto 200px; — определяет строки.
  • gap: 16px; — расстояние между треками (современный аналог grid-gap).

📐 Пример кода: адаптивная 3x2 сетка с фиксированной и резиновой колонкой

.grid-demo {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: auto auto;
  gap: 20px;
}

Сравнение Flexbox и Grid

ХарактеристикаFlexboxGrid
ИзмерениеОдномерная (строка ИЛИ колонка)Двумерная (строки И столбцы одновременно)
Основная задачаВыравнивание элементов в одном направлении, распределение пространства, навигация, карточки.Создание сложных макетов, цельных сеток, расположение элементов в двух осях.
Управление содержимымОриентация на контент (размер элементов влияет на сетку)Ориентация на контейнер (задаём структуру явно)
Когда использоватьМеню, центрирование, небольшие UI-компоненты, выравнивание кнопокОбщая структура страницы, сложные галереи, панели, дашборды, новостные сетки
Свойстваjustify-content, align-items, flex-grow, ordergrid-template-areas, grid-template-columns/rows, gap, justify-items

🔍 Рекомендация: Используйте Flexbox для мелких интерфейсных элементов и внутреннего выравнивания. Применяйте Grid для каркаса страницы, чтобы полностью контролировать расположение блоков. Они отлично сочетаются!

Примеры и учебные задачи

Решение двух базовых задач из семинара: навигация через Flexbox и сетка из трёх одинаковых колонок через Grid.

✅ Задача 1 (Flexbox): навигация с равными расстояниями

Условие: элементы списка — навигация, нужно расположить в ряд с равными промежутками. Используем display: flex; justify-content: space-around;.

  • 🏠 Главная
  • 📰 Блог
  • 📞 Контакты
  • 🔧 Услуги
nav ul {
  display: flex;
  justify-content: space-around;
}

✅ Задача 2 (Grid): три колонки одинаковой ширины независимо от содержимого

Условие: элементы разного размера, но должны образовать 3 одинаковых столбца. Используем grid-template-columns: repeat(3, 1fr);

📦 Короткий текст
📦 Очень длинное содержимое, которое показывает, что ширина ячейки остаётся идеально равной благодаря системе Grid
📦 Средний текст
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
